## 已确认规则和合成预演

D-01：个人存入进入共同账户，代付报销从共同账户付给实际垫付成员；不是向成员收钱。提交者只负责录入，不天然等于出资人。

合成 USD 案例：A/B 各存300 → 共同现金600、贡献600；共同消费100 → 现金500、消费100；A代付120 → 现金仍500、消费220、欠A120；报销50 → 现金450、欠A70、消费仍220；投资买入扣200 → 现金250、成本暂估投资200、共同资产450、扣往来净额380。此处只是 P0 规则解释，不代表已完成账户/债权数据库闭环。

不接入银行/券商交易，不定义个人资产或成员份额。USD/HKD/CNY；界面人民币代码为 CNY。两共同账户不自动补差，费用采用实际扣款/净到账，后续按分期计划实施。

## 现有数据盘点模板

仅执行只读盘点；记录环境、备份编号、查询时间、账本 ID、两名核对成员及证据。没有真实数据库时下表保持“待盘点”，不得填0。

| 对象 | 待核对项目 | 状态 |
|---|---|---|
| households / household_members / profiles | 账本状态、真实 UUID、活跃成员人数、资料权限 | 待盘点 |
| proposals | 待审/逾期/已批准数量、payload版本、重复键、缺必填字段 | 待盘点 |
| ledger_entries | 各状态/币种/类型数量，原币现金，发生/创建时间，同日顺序 | 待盘点 |
| member_id | 旧数据只知提交者；逐笔核对存入人、垫付人、收款人 | 待盘点 |
| reimbursement_claims / settlement_allocations | 无债权的历史代付、无分配的报销、无法确认成员及原单 | 待盘点 |
| investments | 期初数量/成本、与全历史交易是否重复、超卖链路 | 待盘点 |
| investment_valuations | 缺价格、价格minor精度、同日多价、手动/审批来源 | 待盘点 |
| fx_rates | 原币、方向、历史来源/时间、缺失快照；不造实时汇率 | 待盘点 |

历史疑点逐项填写：问题 ID、来源表/主键、账本、类型、日期、原币、原额、已知提交者、待确认付款/收款人、原单分配、候选证据、双方核对结果、处理版本。未知项必须保留待核对。

## 切换日与恢复模板

- 切换日期/账本时区：待双方确认，不使用开发日期自动代填。
- 按币种填写旧共同现金、确认银行期初、确认券商期初、差额（需为0）。负余额保留。
- 切换后只能“确认期初＋后续账户明细”，不能再叠加切换前旧现金事件。
- 投资选择全历史重放或确认期初模式，记录其覆盖区间，不能双计。
- 历史待核对报销不自动按顺序核销，不把 member_id 自动变成债权人。
- 执行前备份编号、预演报告、双方确认、切换版本与回滚/恢复演练记录：待填写。
- 本次未修改生产数据，未执行账户切换或历史数据迁移。
